# hungp.com

**My Personal Digital Garden**

Welcome to my personal corner of the internet. This site serves as a central hub (my personal "Operating System") to connect my diverse projects and creative ideas. It's where I share what I'm building, what I'm learning, and what I'm thinking about.

## 🌟 About This Site

This isn't just a static portfolio; it's a living workspace where I:
-   **Showcase Projects**: A collection of my ventures and coding experiments.
-   **Share Ideas**: A blog for my thoughts on technology, entrepreneurship, and life.
-   **Connect Dots**: Linking concepts and practical application.

## 📚 Documentation

-   **[Architecture Guide](docs/ARCHITECTURE.md)**: Deep dive into the tech stack, design principles, and project structure.
-   **[Future Ideas](docs/SUGGESTIONS.md)**: A collection of feature ideas and concepts for the "Personal OS".

## �️ The Stack

I'm building this site to be fast, modern, and fun to hack on.

-   **Framework**: [Astro](https://astro.build/) - For heavy content with high performance.
-   **Runtime**: [Bun](https://bun.sh/) - Fast tooling for a better dev experience.
-   **UI**: [Shadcn UI](https://ui.shadcn.com/) & [Tailwind CSS](https://tailwindcss.com/) - Clean, accessible, and beautiful design.

## � Running Locally

I use **Bun** for this project.

```bash
# Install dependencies
bun install

# Start development server
bun run dev
```
